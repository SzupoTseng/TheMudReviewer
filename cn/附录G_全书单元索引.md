## G.2　引用结构 — 本书自己的量测

把全书的 `§NNN` 交叉引用扫一遍：

| 项目 | 数值 |
|------|-----:|
| 单元总数 | **82**（001–082，**无编号空缺**） |
| `§` 交叉引用总数 | **604** |
| 被引用过的相异单元 | 74 |
| **指向不存在单元的引用** | **0** |
| 平均每单元被引用 | 约 7.4 次 |

### 被引用最多的十个单元

| 单元 | 次数 | 标题 |
|------|-----:|------|
| **§032** | **36** | 前提被拿掉的那一天 — 服务器搬进分页 |
| §050 | 24 | 17 个 mud，其实是 2 份 mudlib |
| §041 | 24 | 被拿掉的东西 — 套件矩阵 |
| §049 | 22 | 用 LPC 写一整个网络堆栈 — intermud |
| §043 | 20 | ZJMUD 是一套 driver 不知道的协议 |
| §036 | 20 | 三个方向的调用 — efun、apply 与 simul_efun |
| §034 | 19 | 1992 年的改名风波 |
| §037 | 19 | 双堆栈虚拟机 |
| §044 | 19 | 握手那一行 |
| §028 | 18 | Rust 端与桥接 |

**这张表就是本书的骨架。**

被引用最多的 §032（36 次）是「服务器搬进分页」——
它是全书的转折点：前七篇的结论在那里被推翻，后七篇从那里长出来。

而 §043（driver 不知道协议存在）与 §036（三个调用方向）
被引用 20 次，是因为**它们解释了整套协议为什么长成那样**——
撞号、无版本号、逆向着力点，全部回到这两节。

### 从未被引用的八个单元

```
002  字符串常数           012  把协议关进纯函数    014  失败隔离
016  测试分层           029  4 GB 的中间档       030  交付前的清理
070  四种扩充点         076  LPC 标准库与 TUI
```

**这不是缺陷，而且它们分成两类：**

| 类型 | 单元 | 为什么没有被引用 |
|------|------|----------------|
| **方法论类** | 002、012、014、016 | 它们讲的是**通用做法**（读字符串常数、纯函数化、失败隔离、测试分层），后面的章节在**实践**它们而不是引用它们 |
| **收束类** | 029、030、070、076 | 它们本身就是**终点**——综合分析或一次性的交付记录，没有下游 |

**§070（四种扩充点）零引用特别合理**：它是第十一篇的综合单元，
把 §066–§069 收拢起来——**综合者不会被引用，它引用别人。**

> 🔬 **这个量测本身示范了本书的一条规矩**：
> 「零引用」听起来像问题，但**先看分布再下判断**（§050）。
> 分成两类之后，八个里没有一个是真正的孤儿。

## G.4　重跑本附录的量测

```bash
cd designbook

# 单元索引 + 编号完整性
python3 - <<'EOF'
import re, glob
for f in sorted(glob.glob('[0-9][0-9]_*.md')):
    t = open(f, encoding='utf-8').read()
    part = re.search(r'^#\s+(第.{1,3}篇.*)$', t, re.M)
    if part: print('\n##', part.group(1).strip())
    for n, title in re.findall(r'^##\s+(\d{3})　(.+?)$', t, re.M):
        print(f'  {n}  {title}')
EOF

# 引用完整性（找出指向不存在单元的 §NNN）
python3 - <<'EOF'
import re, glob, collections
files = sorted(glob.glob('[0-9][0-9]_*.md')) + sorted(glob.glob('附录*.md'))
units = {m.group(1) for f in files
         for m in re.finditer(r'^##\s+(\d{3})　', open(f, encoding='utf-8').read(), re.M)}
refs, bad = collections.Counter(), []
for f in files:
    for m in re.finditer(r'§(\d{3})', open(f, encoding='utf-8').read()):
        refs[m.group(1)] += 1
        if m.group(1) not in units: bad.append((f, m.group(1)))
print(f'单元 {len(units)}  引用 {sum(refs.values())}  断链 {len(bad)}')
print('零引用:', sorted(u for u in units if refs[u] == 0))
EOF
```

> 💡 **为什么要做这件事**：本书从第一篇就主张「任何断言都要能被重新验证」。
> 一本有 604 条交叉引用的书，**如果没有一支脚本检查它们，
> 那些 `§NNN` 就只是排版**。
> 这份附录是本书对自己套用同一条规矩的结果——
> **而它第一次运行时，断链数就是 0。**
