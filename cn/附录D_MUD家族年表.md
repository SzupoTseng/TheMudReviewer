# 附录 D　MUD 家族年表：1978 – 2026

> 第八、九篇把源流拆在各节里讲。这份附录把它排成一条时间轴，
> 并在每一格标上**本项目手上有没有对应的实物**。
>
> 证据等级：🟡 公开史料与上游档头 ＋ 🟢 本项目封存中的实物与可重跑量测。
> **凡是能用本仓库的文件佐证的，一律标 🟢 并附出处。**

## D.3　中文线：本项目 17 份封存的来历

**这一段是本附录的重点**，因为它有一个少见的性质：
**公开史料、本项目的独立量测、以及封存盘案里的署名，三者互相印证。**

| 年 | 事件 | 对应本项目的什么 |
|---|------|----------------|
| **1993 年底** | **《东方故事》** 开站（交通大学服务器）。采用 **MudOS ＋ TMI Mudlib**，并修改 MudOS 使其能处理中文。**完全舍弃 TMI mudlib 内附的游戏内容**，自行创作武侠背景——第一个把中国武侠题材放进网络游戏的作品 | 🟢 家族 A 的 `dongfanggushi2`（《东方故事Ⅱ》）：仍是 `std/` + `daemon/` + `.lpc` 的 TMI 布局，设置档叫 **`config.ES2`**（§050） |
| **1995 年底** | **《侠客行》**（XKX／XAJH）在《东方故事2》基础上开发，金庸世界观；**第一款简体中文联网游戏** | 🟢 `Creator : ken@XAJH` 出现在 `LPMud-Name/world/adm/daemons/network/services/remote_{q,a}.c` 的档头——**侠客行对 TMI-2 网络层的扩充，签名还在** |
| **1996-05** | **侠客行代码外流**。大量改编版本据此诞生：西游记、风云等分支，以及侠客行 100／侠客行 2000／**北大侠客行** | 🟢 **这就是家族 B 那 16 份**：彼此 Jaccard **0.44–0.90**、共用 `inherit/` + `feature/` + `kungfu/` 骨架（§050） |
| 1996 | 北大侠客行架设于北大物理楼 | 🟢 `pkuxkx.net 8080` 出现在 `nitan7` 的 intermud 名录里（见 D.4） |
| 1998 年底 | 北大侠客行因管理员毕业而搬迁，一度改名红豆侠客行，后恢复原名 | — |
| 2000s | 商业化与分支爆炸；ZJMUD 这类**图形化方言**在此期出现（§056 第 0 代） | 🟢 三个世代的 opcode 方言（第三篇） |
| 2026 | FluffOS 社群的中文 MUD 博物馆收录 **97 份**，全部可在浏览器里跑 | 🟢 本项目 `libs/` 收 **17 份**（§045） |

### 三份证据的收敛

本项目是**先量测、后查史料**的——§050 那套 Jaccard 分析做完时，
还不知道 1996 年的外流事件。三者对得上，是这条血缘图最强的支撑：

```
              史料说                    量测看到                  文件里写着
─────────────────────────────────────────────────────────────────────────────
TMI mudlib    「东方故事采用      15/17 份共用 ~170 个档      Creator : Grendel@Tmi-2
 (1993)        MudOS + TMI」      集中在 daemon/network/     93-08-15
                                  simul_efun 三处
─────────────────────────────────────────────────────────────────────────────
东方故事2     「侠客行在东方       dongfanggushi2 对其他       config.ES2
 (1995 前)      故事2 基础上」      16 份仅 0.012 —— 另一族     es2.muds.net
─────────────────────────────────────────────────────────────────────────────
侠客行外流    「1996-05 外流 →     16 份彼此 0.44–0.90         Creator : ken@XAJH
 (1996-05)     大量改编版本」       = 同一份 code 的分身        config.xajh / xkxnpc/
─────────────────────────────────────────────────────────────────────────────
```

> **三条独立的证据线指向同一张血缘图。**
> 这正是本书第一篇那条规矩的实践：**史料不能单独采信，量测不能单独解释，
> 而当两者加上第三份（档头署名）都同意时，结论才算钉死。**

## D.4　一份意外的史料：intermud 名录快照

§049 讲的那套 1993 年 TMI-2 intermud daemon，会把它见过的节点记在磁盘上。
本项目在 `nitan7` 的封存里挖到那份目录——

```
libs/nitan7 → data/daemon/mrtg/mudlist/    共 118 笔
```

**这是中文 MUD 网络的一份现场快照**，而且是那套 daemon 自己写的。
挑出其中有身分的节点：

| 主机 : 端口 | 是谁 |
|-----------|------|
| `es.muds.net 8000` / **`es2.muds.net 4000`** | **东方故事 / 东方故事Ⅱ** |
| **`pkuxkx.net 8080`** | **北大侠客行** |
| **`hkxkx.com 5000`** | 香港侠客行 |
| `xh.xkx2.com 5555` | 侠客行 2000 系 |
| `china.fengyun.com 6000`、`fy.glqx.com 6666`、`fy4.vmud.com 30004`、`ylfy.91mud.com 4000` | **风云**系（多个分站） |
| `xyj.thu.cn 6666`、`tel.xyj.cn 6666`、`xyzx.91mud.com 7000`、`xyzx.92mud.com 4000/7000/9000` | **西游记**系 |
| `jy.mud.com.tw 6665/6666/7776`、`kk.muds.idv.tw 4000`、`220.135.174.1 6665`、`210.59.236.38 4000` | 台湾站（金庸系等） |
| `hell.52mud.com 2008`、`mud.52mud.com 8888`、`mud123.com 3000/5000/5555/7000`、`muds.cn 5000/5555` | 大陆入口／多开站 |
| 其余 60 余笔 | 裸 IP + 端口（`222.186.34.42 1002`、`202.100.210.107 5555`…） |

**三个可以直接读出来的观察：**

1. **家族树在名录里是可见的**——`es`／`es2`／`xkx`／`fengyun`／`xyj` 同时在线，
   正好是 D.3 那条「东方故事 → 侠客行 → 外流分支」的下游全景。
2. **同一个主机开多个端口是常态**（`mud123.com` 四个端口、`92mud.com` 三个端口、
   `jy.mud.com.tw` 三个端口）——一台机器跑多份 mudlib，
   这与本项目 17 份封存的来源形态一致。
3. **裸 IP 占一半以上**——没有网域、没有 TLS、没有认证（§049 的罩门）。
   这份名录本身就是那个时代网络信任模型的切片。

> 🔍 **这份快照对逆向工作的价值**：它是**由系统自己产生的**历史纪录，
> 不是任何人事后的整理。本书第一篇的证据等级表里，
> 这种东西的位阶很高——**它没有叙事动机**。
> 遇到来历不明的封存时，优先去找这类「系统自己写下的东西」：
> 名录、log、缓存、备份文件名、swapfile 的文件名（§050 那个
> `swapfile.MudCastle.5555` 就泄漏了原站名与端口号）。

## D.5　一句话总结这张年表

```
1978  多人虚拟世界诞生
1989  driver / mudlib 分家 ────────┐  这一刀决定了后面 37 年
1992  MudOS 分支（TMI）            │  ——游戏住在脚本层，
1993  TMI-2 mudlib ────┐           │    所以三十年后还读得懂
1993  东方故事（中文化）│           │
1995  侠客行           │ 这条线     │
1996  外流 → 16 份分身 ┘ 是本项目   │
2026  FluffOS WASM ────────────────┘  整台 driver 进了浏览器分页
2026  本项目：17 份封存，17 份可玩
```

**横跨这 48 年、始终没有变过的只有一件事：`write()` 出去的是文本。**
本书第二篇那 116 个 opcode、第九篇那四代频外协议，
全部都是在同一个前提上想办法——**而那个前提，是 1978 年定下的。**
